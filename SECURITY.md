# Security

Please don't open a public issue for a security problem. Report it privately instead:
**[Report a vulnerability](https://github.com/dillonco/presentation-game/security/advisories/new)**.

Say what you found, how to reproduce it, and what someone could do with it. Fixes go into `main` only.
For running your own server safely, see the environment section of the [README](README.md#play-it-on-the-night).
